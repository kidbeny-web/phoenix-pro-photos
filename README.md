# Phoenix Pro Mesure

Mètre en réalité augmentée pour Android (ARCore) : on vise, on pose deux points, la distance s'affiche.

- Mesure en direct sur les murs, le sol, les meubles (détection des surfaces et de la profondeur)
- Plusieurs mesures à l'écran, annuler, tout effacer
- Historique par pièce : fenêtres, murs, portes, meubles, emplacements, avec repères pour les rideaux
- Saisie à la main pour les téléphones non compatibles ARCore

Téléchargement : onglet **Releases** → `mesure-derniere-version` → `PhoenixProMesure.apk`.
