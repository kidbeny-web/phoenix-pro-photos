# Phoenix Pro Retouche (Android)

Retouche photo pro : réglages type Lightroom, couleurs TSL, courbes, recadrage, retouche locale (masque + correcteur), calques, filtres, amélioration auto, ouverture des RAW (aperçu intégré).

- L'éditeur est dans `app/src/main/assets/index.html` (HTML + WebGL).
- Chaque envoi sur la branche `retouche` fabrique l'APK : release **retouche-derniere-version**.
- Les photos exportées vont dans *Images › Phoenix Pro Retouche*.
