# Phoenix Pro Cam

Transforme un vieux téléphone Android en caméra de surveillance, sans cloud ni abonnement.

- **Mode Caméra** (vieux téléphone) : détection de mouvement, enregistrement de chaque passage en images, fonctionne écran éteint
- **Mode Visionneuse** (votre téléphone) : caméras trouvées automatiquement sur le Wi-Fi, direct, historique des passages, alertes
- Tout passe par le Wi-Fi de la maison ; chaque caméra est protégée par un code à 6 chiffres

Prévenez les personnes filmées chez vous (aide à domicile, invités) et ne filmez ni la voie publique ni chez les voisins.

Téléchargement : onglet **Releases** → `cam-derniere-version` → `PhoenixProCam.apk`.
