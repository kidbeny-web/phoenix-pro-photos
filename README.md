# Phoenix Pro Sonomètre

Sonomètre pondéré A et preuve de nuisances sonores pour Android.

- Mesure en dB(A) (pondération A, constante rapide 125 ms), calibrage réglable
- Mesure longue en arrière-plan, écran éteint (notification permanente)
- Événements horodatés au-dessus d'un seuil, avec extrait audio (WAV) et empreinte SHA-256
- Bruit de fond (L90), émergence de chaque événement, L10, LAeq, maximum
- Rapport PDF à partager (syndic, mairie, conciliateur), avec ou sans les extraits audio

Téléchargement : onglet **Releases** → `sonometre-derniere-version` → `PhoenixProSonometre.apk`.

Le rapport est un relevé personnel : il ne remplace pas un constat de commissaire de justice
ni une mesure faite avec un sonomètre homologué.
