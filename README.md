# Phoenix Pro Fichiers

Gestionnaire de fichiers pour Android, sans publicité.

- Espace de stockage par catégorie, fichiers récents, gros fichiers
- Parcourir, trier, sélection multiple, copier / couper / coller, renommer, nouveau dossier, partager, ouvrir avec
- Corbeille (30 jours), compression et extraction zip, recherche dans tout le téléphone, carte SD

Téléchargement : onglet **Releases** → `fichiers-derniere-version` → `PhoenixProFichiers.apk`.
