# Phoenix Pro Testeur

Testeur de téléphone d'occasion pour Android : à faire devant l'acheteur ou le vendeur.

- Tests automatiques : fiche de l'appareil, batterie (santé estimée, cycles, température), Wi-Fi, Bluetooth, NFC, signes de root
- Tests guidés : écran et pixels morts, tactile, multitouch, haut-parleur, écouteur d'appel, micro, vibreur,
  boutons de volume, caméras avant et arrière, flash, capteurs, GPS, port de charge, capteur d'empreinte
- Rapport PDF à envoyer à l'acheteur (Leboncoin, Vinted…)

Téléchargement : onglet **Releases** → `testeur-derniere-version` → `PhoenixProTesteur.apk`.
