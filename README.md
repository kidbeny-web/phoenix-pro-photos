# Phoenix Pro Photos — Android

Application Android de gestion de photos : visages (reconnaissance 100 % sur le téléphone), carte des lieux, chronologie, favoris, et synchronisation avec Phoenix Pro Photos sur le PC.

L'APK est fabriqué automatiquement par GitHub Actions à chaque modification : voir l'onglet **Releases** → « derniere-version » → `PhoenixProPhotos.apk`.
