# Phoenix Pro Coffre

Coffre à codes chiffré pour Android : Wi-Fi, digicodes, codes d'alarme, cadenas, numéros de série, références de pièces.

- Déverrouillage par empreinte ou visage (clé protégée par le Keystore Android) ou par code à 6 chiffres
- Chiffrement AES-256-GCM, clé dérivée du code par PBKDF2 (150 000 itérations)
- Captures d'écran bloquées, verrouillage automatique, presse-papiers effacé après 45 s
- QR code Wi-Fi pour partager la connexion
- Sauvegarde chiffrée par mot de passe (export / import), aucun envoi sur Internet

Téléchargement : onglet **Releases** → `coffre-derniere-version` → `PhoenixProCoffre.apk`.
