# Phoenix Pro Notes

Prise de notes pour Android, pensée pour le stylet (S Pen des Galaxy, ou tout stylet Android).

- Écriture à la main sensible à la pression, surligneur, gomme, annuler / rétablir
- Bouton latéral du stylet maintenu = gomme ; la main posée sur l'écran ne dessine pas (le doigt fait défiler)
- Conversion de l'écriture manuscrite en texte (français, sur le téléphone)
- Notes au clavier, fonds de page (lignes, quadrillage, points), couleurs, épingles, recherche, export PDF

Téléchargement : onglet **Releases** → `notes-derniere-version` → `PhoenixProNotes.apk`.
