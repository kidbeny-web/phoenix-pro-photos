# Phoenix Pro Détecteur

Détecteur pour Android, à partir des capteurs du téléphone.

- Métaux : capteur magnétique, étalonnage, bips et vibrations selon l'intensité (métaux ferreux à quelques centimètres)
- Caméras cachées : reflets d'objectif (flash), lumière infrarouge (caméra avant), appareils du réseau Wi-Fi qui ressemblent
  à des caméras, liste des cachettes à vérifier

Un téléphone ne remplace pas un détecteur de câbles électriques : coupez le courant avant de percer.

Téléchargement : onglet **Releases** → `detecteur-derniere-version` → `PhoenixProDetecteur.apk`.
